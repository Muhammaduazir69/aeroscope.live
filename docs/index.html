The problem

Raw ADS-B is a firehose.
AeroScope makes it legible.

Every airliner, business jet, helicopter and many drones broadcast their position on 1090 MHz. Dozens of volunteer networks publish that traffic for free — but as undifferentiated dots. The hard part isn't collecting positions; it's answering the real questions about a specific patch of sky.

Architecture

From 1090 MHz to an explainable verdict

A two-tier loop keeps the picture both fresh and deep: a lightweight position refresh keeps markers moving every few seconds, while the heavier enrichment-and-detection pipeline runs on its own cadence so analysis never blocks motion.

01

Ingest

60+ crowdsourced ADS-B feeds plus satellite ADS-B, fetched per active map region.

→
02

Fuse

De-duplicate by ICAO 24-bit address; reconcile terrestrial and satellite views.

→
03

Enrich

Registry, Kalman tracks, DO-260B integrity, pattern-of-life, 8-factor score.

→
04

Detect

Six detectors vote; a flag fires only on ≥2-detector consensus.

→
05

Serve

WebSocket + REST to a client that dead-reckons each marker for smooth motion.

→

The detection layer is deliberately built from established, auditable libraries — River, scikit-learn, pykalman, OpenAP, stumpy, PyOD — rather than an opaque neural network. Every flag traces back to the features that produced it. There is no PyTorch and no reinforcement learning in the deployed system; an earlier RL prototype was evaluated and retired in favour of this transparent stack.

How the score works

An attention-ranker, shown working

The score exists to sort, not to accuse. It rises when several independent indicators fire at once; the contributing factors are always displayed.

0–40  Routine traffic — minor or no anomalies.
41–60  Moderate — multiple factors present.
61–100  Elevated — several strong indicators agree.

Open research

The AeroScope ADS-B Anomaly Benchmark

Anomaly detectors in aviation security are hard to compare because there is little shared, labelled, openly-licensed data. AeroScope publishes a benchmark to help fix that — real traffic, a documented attack taxonomy, and an honest baseline.

What's in it

The benchmark pairs real airborne traffic, captured live from crowdsourced receiver feeds across multiple regions and de-duplicated by ICAO 24-bit address, with synthetically injected attacks following the standard taxonomy in the ADS-B security literature — altitude tampering, velocity tampering, ghost kinematics and integrity-field downgrade (methodology after Habler & Shabtai, Computers & Security, 2018).

Each record carries 38 documented columns: raw ADS-B fields, the integrity fields that matter for spoofing detection (NIC, NACp, NACv, SIL), derived self-consistency features (geometric-vs-barometric altitude, ground-speed-vs-Mach residual, track-vs-heading difference), and the anomaly score from the deployed scikit-learn IsolationForest baseline — which measured ROC-AUC ≈ 0.87 (≈50% detection at a strict ~2% false-positive rate, threshold calibrated on held-out real traffic).

FAQ

Questions, answered plainly

What exactly is AeroScope?
An observer-relative airspace-intelligence platform. It ingests aircraft positions from 60+ public ADS-B feeds, fuses and de-duplicates them, and presents a real-time, explainable view of the aircraft over a chosen point — identity, behaviour, signal integrity, and which ones warrant attention. It also publishes an open anomaly-detection benchmark.
Does it use deep learning or reinforcement learning?
No. The anomaly layer is deliberately torch-free and built on established libraries — River, scikit-learn IsolationForest, pykalman, OpenAP, stumpy and PyOD — with consensus voting (≥2 detectors must agree). There is no PyTorch and no reinforcement learning; an earlier RL prototype was retired in favour of this transparent, reproducible stack.
Is the threat score an accusation?
No. It is a 0–100 attention-ranker that sorts a busy list, computed from eight transparent weighted factors, with the contributing factors always shown. It tells an operator where to look first; it does not pass judgement.
What's in the open benchmark, and can I cite it?
38 documented columns pairing real airborne traffic with synthetically injected attacks following the standard ADS-B security taxonomy, including the NIC/NACp/SIL integrity fields and derived self-consistency features. The bundled IsolationForest baseline measured ROC-AUC ≈ 0.87. It is CC-BY 4.0 — cite as "AeroScope ADS-B Anomaly Benchmark v1, aeroscope.live".
